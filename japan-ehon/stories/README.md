# Adding a story to japan-ehon

Each story is one file here, `stories/<id>.js`, exporting one plain story object with
`module.exports = { ... }`. Running `node engine/build-stories.js` (from the repo root) collects
every file in this folder, sorts them by filename, and writes the combined, browser-loadable
`japan-ehon/stories.js` — never edit `stories.js` directly, it is generated and will be
overwritten. CI (`--check`) fails if `stories.js` is stale, the same way `book-pages.test.js`
already does for generated per-book pages.

`<id>.js`'s filename does not have to match the story's `id` field, but keeping them the same
(e.g. `momotaro.js` for `id: "momotaro"`) makes the folder easy to scan. Sort order only affects
the shelf order, so name files so the list reads in the order you want stories to appear
(a numeric prefix like `01-momotaro.js` works well if shelf order matters more than the id).

## Shape (mirrors taiwan-ehon/stories.js, plus optional `en`)

```js
module.exports = {
  id: 'momotaro', // stable, unique across this series; becomes the book's URL and analytics book_id — never rename one after publishing
  title: {
    ja: '{桃太郎|ももたろう}',      // {漢字|かんじ} marks furigana; plain kana elsewhere
    zh: '桃太郎',
    en: 'Momotaro, the Peach Boy', // include when this book has English narration
    zhuyin: 'ㄊㄠˊ ㄊㄞˋ ㄌㄤˊ',    // one 注音 syllable per Han character in `zh`, space-separated
  },
  tagline: { ja: '...', zh: '...', en: '...' },
  origin: { ja: '...', zh: '...', en: '...' },   // e.g. "にほんの むかしばなし" / "日本民間故事"
  credit: { ja: '...', zh: '...', en: '...' },   // source/adaptation note shown on the last page
  theme: { accent: '#273968', soft: '#d7dcee' }, // optional per-book accent override; omit to use the series theme
  pages: [
    {
      id: 'cover', // then 'p01', 'p02', ... then 'end' — same convention as taiwan-ehon
      image: 'images/momotaro/cover.webp',
      alt: { ja: '...', zh: '...', en: '...' },
      lines: [
        {
          id: 'cover-1', // unique within the story; becomes the narration clip filename
          speaker: 'narrator', // must be a key already in generate_gemini_audio.py's SPEAKERS map, or a new one added there
          style: 'warm, inviting storyteller opening a picture book', // direction for the TTS voice only, never shown
          ja: '...', zh: '...', en: '...',
          jaTts: '...', // optional: overrides what is spoken (not shown) in ja, to fix a misreading
          zhTts: '...', // same, for zh
          enTts: '...', // same, for en
          zhuyin: '...', // one 注音 syllable per Han character in this line's `zh`
        },
      ],
    },
  ],
};
```

## The `en` field is optional, per line and per label

English is optional in the schema, but all eight currently published stories include English text
and narration. See this series' README for the selected voice and audition notes. A story with no
`en` fields at all reads and narrates in `ja`/`zh` exactly like a taiwan-ehon story; the engine only
ever displays/narrates the languages this series' `series.config.js` declares
(`languages: ['ja', 'zh', 'en']` here) and that are actually present on a given line, so a
partially-translated story never shows a blank English line — it simply behaves as ja/zh-only for
any line missing `en`.

## Images and audio

- Pictures: `japan-ehon/images/<id>/<page-id>.webp`, one per page, matching taiwan-ehon's
  convention (illustration style/prompt discipline is in the two research reports at
  `/Users/yc.keng/Documents/Codex/data/ehon-series-research{,-sonnet}/report.md`, Part 3).
- Narration: generated by `generate_gemini_audio.py` into
  `japan-ehon/audio/<id>/<ja|zh|en>/<line-id>.mp3` — run it from inside `japan-ehon/` (see that
  script's own `--help` and this series' README).

## Registering a finished story

1. Add `stories/<id>.js` (this file's shape).
2. Add `images/<id>/*.webp` for every page.
3. From the repo root: `node engine/build-stories.js` (rebuilds `stories.js`), then
   `node japan-ehon/generate-book-pages.js` (adds the static `<id>/index.html` page).
4. Generate narration: `cd japan-ehon && python3 generate_gemini_audio.py --confirm`.
5. `node --test engine/*.test.js` from the repo root to confirm nothing regressed.

No other file needs to change — the shelf, offline downloads, and PWA precache list are all
derived from `stories.js`.

## Story writing process

Per the standing house rule: draft the story on Claude Opus, then have GPT-6 Sol review it
adversarially (factual/source fidelity, age-appropriateness, cultural framing, and equivalence
across all three languages) and revise before recording narration or generating art. This applies
to every story text in this folder — the story is the part of this product most worth getting right.
