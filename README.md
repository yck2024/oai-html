# OAI HTML Pages

Public static HTML pages generated for sharing.

## Gallery

- https://yck2024.github.io/oai-html/
- Neovim beginner visual guide
- Herdr Keyboard Visual Guide (EN / 繁中)
- Pi + Luna + Automic Vault

The root site is deployed with GitHub Pages from `.github/workflows/pages.yml`.

## Publish-page skill

Reusable publishing instructions live at:

`skills/publish-page/SKILL.md`

The intended shortcut is simply:

> publish page

The skill defines the default destination as this repository, checks the HTML for secrets/private data, publishes it under a stable slug, updates the root gallery, and verifies the GitHub Pages deployment.
