Herdr keyboard, decoded

Stop memorizing symbols. Learn the model.

The default model is tmux-style: first enter Herdr command mode with Ctrl+B, release it, then press the action key. You do not hold all keys together.

#1 The one thing to remember
Ctrl+B →RELEASE →C
Result: new tab. Think “call Herdr, then give it a command.”

Optional: make Herdr feel more “normal”

Add prefix-free Ctrl+Alt shortcuts

Herdr's docs recommend Ctrl+Alt as a relatively safe family for direct terminal shortcuts. Keep the defaults and add direct chords on top. 

[keys]
focus_pane_left  = ["prefix+h", "ctrl+alt+h"]
focus_pane_down  = ["prefix+j", "ctrl+alt+j"]
focus_pane_up    = ["prefix+k", "ctrl+alt+k"]
focus_pane_right = ["prefix+l", "ctrl+alt+l"]

new_tab          = ["prefix+c", "ctrl+alt+c"]
split_vertical   = ["prefix+v", "ctrl+alt+d"]
split_horizontal = ["prefix+minus", "ctrl+alt+shift+d"]
zoom             = ["prefix+z", "ctrl+alt+z"]
Mac note: direct shortcuts must survive macOS + Terminal.app/iTerm/Ghostty before Herdr can receive them. If one does nothing, the outer terminal may have captured it.
